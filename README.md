# Reverse Mortgage Training Course

An interactive training module for reverse mortgage education.

## Project Structure

```
├── index.html          # Main training module (add your HTML here)
├── css/                # Stylesheets
├── js/                 # JavaScript files
├── assets/
│   ├── images/         # Image assets
│   └── videos/         # Video assets
└── README.md
```

## Getting Started

1. Add your HTML training content to `index.html`
2. Place any stylesheets in the `css/` directory
3. Place any JavaScript files in the `js/` directory
4. Add images and media to the `assets/` folder

## Usage

Open `index.html` in a web browser to view the training module.
